# Synapse Browser v1.0.6 patch

## Scope

This patch addresses two real-world bugs without changing the published v1.0.5 release or the OLED-black and metallic-silver visual language.

## Fixes

The Settings AI-provider selector is now an accessible custom combobox and popover. It uses an OLED-black surface, silver-gray text and borders, a restrained selected state, visible hover/focus states, Escape handling, and ArrowUp/ArrowDown keyboard selection. This avoids the white platform-native `<select>` menu while preserving provider state and existing secure provider IPC.

The native browser WebContentsView geometry is now driven by the measured renderer container without a permanent 380-pixel ORION reservation. BrowserView explicitly recalculates on active-tab and ORION layout-key changes in addition to ResizeObserver and window resize notifications. The renderer remains visible while ORION is open and can expand back to the full measured width after ORION closes.

## Additional browser UX work

The patch also replaces the no-session startup placeholder with a renderer-owned Synapse Home surface. A clean session now has one intentional New Tab entry rather than an immediately loaded duplicate Google page. Home provides web search/URL entry, persistent shortcut tiles with add/edit/delete/reorder controls, built-in OLED/graphite/studio wallpaper choices, local image wallpaper input, intensity and blur controls, and a persisted local preference model. External websites continue to use native Electron WebContentsView instances; Home remains renderer-owned.
